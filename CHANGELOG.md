# Журнал змін

Формат версій: `vМАЖОР.МІНОР.ПАТЧ`. Версії `v0.*` позначаються на GitHub як попередні.

## v1.0.0

Перший повноцінний випуск.

- Runner: запуск сценарію серією з прогрівом, збір часу, пікової пам'яті й процесорного часу, відбиток середовища, відправка результату на сервер з трьома спробами, збереження у файл і повторна відправка командою `send`, переривання через `Ctrl+C` із відправкою часткової серії, код виходу 3 для помилок запису.
- Server: збереження результатів у SQLite з транзакціями й обмеженнями цілісності, статистика запуску, порівняння середовищ, базові лінії, виявлення регресій, дашборд, експорт CSV, HTML-звіт по сценарію, єдиний формат помилок, відповідь 500 без технічних подробиць.
- Якість: тести на трьох ОС у CI, покриття рядків не менше 80% для server і runner, звіт статичного аналізу, звіти про крайні випадки.
- Документація: README з запуском з нуля, `docs/architecture.md`, `docs/test-cases.md`, `docs/contract.md`, журнал рішень `docs/decisions.md`.
- Релізні архіви `win-x64`, `linux-x64`, `osx-arm64` без потреби у встановленому .NET; smoke test перевіряє API, дашборд і HTML-звіт.

## v0.2.1

- Виправлений тег після v0.2: релізні архіви `win-x64`, `linux-x64`, `osx-arm64` із самодостатніми збірками сервера, runner і тестових застосунків; автоматична публікація релізу за тегом.
- Тестові застосунки `CpuBound`, `SortFile`, `Flaky` і набір сценаріїв у папці `scenarios`.

## v0.2

- Runner: прогрів, переривання серії, збереження результату при недоступному сервері й команда `send`.

## v0.1

- Каркас рішення, контракт обміну, схема бази й шар доступу до даних, API збереження запусків, статистика та порівняння, runner із завантаженням сценаріїв, запуском процесів, метриками й відправкою результатів, CI на трьох ОС.
